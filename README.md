# MKLHC-App

MKLHC-App is an app that pairs with and drives the 802.11 RC toy karts, codename Fuji, manufactured and distributed by a well-known Japanese entertainment and technology company. It runs from a stock Android phone (or desktop) using a commercial USB Wi-Fi adapter, with no original host console and no rooting or flashing.

## Status

Early development.
